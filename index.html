Frequently asked questions

What is a HEIC file?

HEIC is an image format commonly used by Apple devices to store photos efficiently.

Will converting HEIC to JPG reduce quality?

JPG uses lossy compression. A higher quality setting generally preserves more visual detail but may create larger files.

Are my photos uploaded?

This prototype performs conversion in the browser using a client-side library. Because the library is loaded from a CDN, verify network requests and the deployed implementation before making a definitive privacy claim.

Why did a file fail?

Some files may be unsupported, damaged, unusually large, or incompatible with a browser or device. Try a smaller file or another browser if conversion fails.
